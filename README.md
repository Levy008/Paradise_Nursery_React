# Paradise Nursery React

## Project name

Paradise Nursery is a React-based plant ecommerce store.

## What the app does

The app provides a three-page plant shopping experience:

- A full-screen landing page introducing Paradise Nursery
- A product listing page with categorized plants and Add to Cart actions
- A shopping cart page with quantity controls, item deletion, subtotal, and
  Continue Shopping/Checkout actions

Cart state is managed with a Redux Toolkit slice and shared across the
product listing and cart pages.

## Run locally

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
